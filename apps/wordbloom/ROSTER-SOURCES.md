# Football collection sources

Snapshot prepared 2026-11-05. The collection uses recognisable international footballers as an educational theme, not an official ranking or an assertion of 2026 club contracts or tournament selection. Countries and broad GK / DF / MF / FW game roles are used instead of changeable club names, ages, ratings or live statistics.

Primary references consulted:
- FIFA 2026 squad announcements: https://www.fifa.com/en/articles/all-world-cup-squad-announcements
- FIFA 2026 player statistics: https://www.fifa.com/en/tournaments/mens/worldcup/canadamexicousa2026/statistics/player-statistics
- FIFA / national-team roster material linked from those pages.
